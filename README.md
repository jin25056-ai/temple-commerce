# 절에간성경 FOOD MARKET — 디자인 v2

기존 Vite 시연용 프로젝트를 기반으로, 제공된 모바일 시안에 맞춰 PC/모바일 반응형 홈을 개편했습니다.

## 실제 영상
- 대표 영상: https://www.youtube.com/watch?v=FPG3i1JN87M
- 쇼츠: https://www.youtube.com/shorts/7yOQmHBmSOo
- 쇼츠: https://www.youtube.com/shorts/LGELrqKpPFA

영상 카드를 누르면 유튜브 임베드 팝업이 열립니다. 유튜브 측에서 임베드를 제한한 영상은 팝업의 '유튜브에서 직접 보기' 링크를 이용하세요.

## 시연 기능
상품 목록/상세, 검색, 카테고리, 장바구니, 찜, 영상 재생 팝업. 상품과 가격은 샘플이며 실제 판매·결제는 지원하지 않습니다. **영상과 샘플 상품이 실제 연관되어 있다는 뜻이 아닙니다.**

## 배포
GitHub 저장소의 `temple-commerce-demo` 폴더에 `index.html`, `src.js`, `style.css`, `package.json`, `README.md`를 교체해 커밋하면 연결된 Vercel이 재배포합니다. Root Directory는 기존과 동일하게 `temple-commerce-demo`를 유지합니다.

## 로컬 실행
`npm install` 후 `npm run dev` / 빌드 확인 `npm run build`.
